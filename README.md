# Лабораторная работа: растеризация и заливка

## 1. Назначение программы

Программа демонстрирует построение отрезков и многоугольников на дискретной двумерной сетке, а также два способа заливки внутренней области многоугольника.

Реализованы:
- алгоритм Брезенхэма;
- алгоритм DDA и сравнение с Брезенхэмом;
- построение контура многоугольника;
- Flood Fill с 4- и 8-связностью;
- Scanline Fill;
- вывод сетки в консоль и сохранение результата в PGM.

## 3. Представление сетки

Сетка хранится в двумерном массиве символов фиксированного размера.

- `Grid` — структура, содержащая массив ячеек.
- `Point` — структура с координатами `x` и `y`.
- `cells[y][x]` — обращение к ячейке: сначала строка (`y`), затем столбец (`x`).

Используемые символы:
- `.` — пустая ячейка;
- `#` — граница многоугольника или отрезок;
- `*` — закрашенная область.

Размеры сетки и другие постоянные значения задаются именованными константами.

## 4. Алгоритм Брезенхэма

Алгоритм выбирает пиксели, которые наиболее близко приближают идеальный отрезок на целочисленной сетке.

Для концов отрезка A(x1,y1) и B(x2,y2) вычисляются абсолютные приращения:

    deltaX = |x2 - x1|
    deltaY = |y2 - y1|

Направления движения по осям задаются величинами `stepX` и `stepY`, равными 1 или -1.

Начальная ошибка:

    error = deltaX - deltaY

На каждой итерации вычисляется удвоенная ошибка:

    doubledError = 2 * error

Удвоение позволяет сравнивать ошибку с порогами `-deltaY` и `deltaX` без дробных вычислений. По результатам двух независимых проверок алгоритм изменяет координату `x`, координату `y` или обе координаты. Так выбирается следующий пиксель, приближающий идеальную прямую.

## 5. Алгоритм DDA

DDA строит отрезок последовательным добавлением приращений координат.

Сначала определяется число шагов:

    N = max(|deltaX|, |deltaY|)

Затем вычисляются приращения на один шаг:

    incrementX = deltaX / N
    incrementY = deltaY / N

На каждом шаге текущие вещественные координаты увеличиваются на соответствующие приращения. Для выбора ячейки сетки координаты округляются до целых.

Если `N == 0`, отрезок вырождается в одну точку. Этот случай обрабатывается отдельно, чтобы не выполнять деление на ноль.

DDA и Брезенхэм получают одинаковые начальную и конечную точки. Их результаты могут отличаться из-за вещественных вычислений и правил округления.

## 6. Построение многоугольника

Многоугольник задаётся массивом вершин. Для каждой вершины строится отрезок до следующей вершины.

Индекс следующей вершины вычисляется выражением:

    nextVertex = (vertex + 1) % vertexCount

Операция остатка от деления обеспечивает замыкание контура: после последней вершины следующей становится первая. Для растеризации каждого ребра вызывается алгоритм Брезенхэма.

## 7. Flood Fill

Flood Fill выполняет заливку от заданной точки-затравки.

Алгоритм:
1. Проверяет, что координаты находятся внутри сетки.
2. Проверяет, что текущая ячейка пустая.
3. Закрашивает ячейку, чтобы повторно в неё не заходить.
4. Переходит к соседним ячейкам.
5. Завершает ветвь обхода, если координаты вышли за границы или ячейка уже не пустая.

При 4-связности проверяются соседи сверху, снизу, слева и справа. При 8-связности дополнительно проверяются четыре диагональных соседа.

В текущей реализации обход выполняется рекурсивными вызовами. Функция возвращает количество закрашенных ячеек. Счётчик нужен для получения результата и сам по себе не управляет завершением заливки.

## 8. Scanline Fill

Scanline — построчный алгоритм заливки. Сетка обрабатывается строка за строкой.

Для каждой строки задаётся координата сканирования:

    scanY = row

Для каждого ребра определяются минимальная и максимальная координаты по вертикали:

    minimumY = min(y1, y2)
    maximumY = max(y1, y2)

Горизонтальные рёбра пропускаются. Остальные рёбра учитываются, если текущая сканирующая линия попадает в полуинтервал:

    scanY >= minimumY && scanY < maximumY

Такое правило позволяет не учитывать общую вершину двух соседних рёбер дважды.

### Вывод формулы пересечения

Пусть ребро соединяет точки A(x1,y1) и B(x2,y2). Уравнение прямой через эти точки:

    y - y1 = ((y2 - y1) / (x2 - x1)) * (x - x1)

На сканирующей линии координата `y` равна `scanY`. Подставим её:

    scanY - y1 = ((y2 - y1) / (x2 - x1)) * (x - x1)

Выразим `x`:

    x = x1 + ((scanY - y1) * (x2 - x1)) / (y2 - y1)

Эта формула вычисляет координату `intersectionX` пересечения горизонтальной линии с ребром. Горизонтальные рёбра заранее исключаются, поэтому знаменатель `y2 - y1` не равен нулю.

Все найденные координаты пересечений сортируются по возрастанию. Затем они обрабатываются парами: первая и вторая, третья и четвёртая и так далее. Каждая пара задаёт промежуток внутри многоугольника.

В текущей версии программы границы столбцов определяются так:

    startColumn = ceil(firstX)
    endColumn = floor(secondX)

`ceil` округляет значение вверх, а `floor` — вниз. Цикл закрашивания использует условие `column <= endColumn`, поэтому конечный столбец включается в обработку. Закрашиваются только пустые ячейки, чтобы не перезаписывать контур.
